# 第三周代码阅读作业
## 1. SampleFireBrigade.java 中 sense() 方法的作用
1. 感知消防车当前所处位置，扫描地图中的避难所、被困人员等目标实体；
2. 筛选符合救援条件的目标，存入 targets 集合；
3. 调用静态排序方法，按照距离对目标重新排序；
4. 更新消防车内部待救援目标列表，为后续救援逻辑提供环境数据。
## 2. for (Iterator it = targets.iterator(); it.hasNext();) 语法相关
### 语法名称
手动迭代器遍历循环，直接使用集合的 Iterator 对象完成遍历。
### 不使用增强 for 循环的原因
1. 迭代器遍历过程中支持 `it.remove()` 安全删除集合元素；增强 for 循环遍历中删除元素会抛出并发修改异常；
2. 业务逻辑中需要在遍历中途移除失效救援目标，迭代器可以精细控制遍历、删除操作；
3. 该项目早期兼容低版本 Java，增强 for 循环是 Java 5 才新增的语法，原代码选用兼容性更好的迭代器写法。
