# 1.Server启动顺序

1.加载kernel.cfg配置文件，读取仿真全局参数（地图、时间步、灾难初始条件）
 2.启动仿真内核，加载地图数据，初始化灾难世界（建筑、道路、火源、伤员初始状态）
 3.开启TCP监听接口，等待外部Agent建立网络连接
 4.全部Agent连接完成之后，启动仿真时间步循环，逐帧推进仿真，接受Agent行动、更新世界状态。

# 2.adf-core-java主要包及作用
1.core包：存放框架对外暴露的接口与抽象基类，定义Agent生命周期、世界模型、组件、通信的抽象规范，提供开发Agent需要的API，用户代码面向该包编程。

2.impl包：对core包接口的具体实现，包含网络收发、路径规划、事件循环、实体解析等底层完整逻辑，属于框架内部实现。

# 4. Agent生命周期方法

1. postConnect()：Agent成功和仿真服务器建立TCP连接后调用，只执行一次。适合做初始化工作：读取配置、初始化知识库、预处理地图信息。

2. think()：每一个仿真时间步都会循环调用。每一帧Agent在这里感知世界、做决策、生成行动指令发送给仿真器。
