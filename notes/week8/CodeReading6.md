# CodeReading6 学习记录

## 1. Agent 和 Server 之间用的是什么协议？数据是什么格式？
- **协议**：TCP（传输控制协议），基于可靠的字节流传输。
- **数据格式**：使用 **Protobuf（Protocol Buffers）** 进行序列化后的二进制数据。项目中的 `RCRSProto.java` 定义了消息结构，所有通信内容均按该 schema 编码。

## 2. 数据为什么要序列化？直接传 Java 对象行不行？
- **序列化原因**：
    1. **跨语言兼容**：Agent 和 Server 可能用不同语言实现（如 C++、Python），Protobuf 是语言中立的。
    2. **网络传输**：必须将内存中的对象转换成字节流才能在网络中传输。
    3. **性能与体积**：Protobuf 序列化后数据小、解析快，比 Java 原生序列化高效。
    4. **版本演进**：Protobuf 支持向前/向后兼容，便于协议升级。

- **直接传 Java 对象不行**：
    - Java 序列化后的数据体积大、效率低，且只能被 Java 解析；
    - 无法跨语言交互；
    - 在分布式系统中，Java 序列化还容易引起安全问题和版本不一致。
