# 第二周Git学习笔记
## 一、四大核心区域
1. 工作区：本地电脑存放代码的文件夹，日常编辑、修改文件
2. 暂存区：临时缓存文件修改，执行git add后文件存入此处，等待提交
3. 本地仓库：项目内隐藏.git文件夹，永久保存版本快照，记录完整提交历史
4. 远程仓库：GitHub云端仓库，用于代码备份、多人协作同步

## 二、本周核心Git命令含义
1. git clone [仓库地址]：将远程GitHub仓库完整下载到本地电脑
2. git add .：把工作区所有修改添加至暂存区；指定单个文件写 git add 文件名
3. git commit -m "描述文字"：将暂存区改动提交保存到本地仓库，-m后填写本次修改说明
4. git push origin 分支名：把本地分支代码上传推送至自己的GitHub远程仓库
5. git pull：拉取远程仓库最新代码，自动合并到本地当前分支
6. git branch：查看本地所有分支；git branch 分支名 仅创建新分支，不切换
7. git checkout 分支名：切换到指定已存在的分支
8. git merge 分支名：将目标分支代码合并进当前所在分支
9. git status：查看文件当前状态（未跟踪、已修改、已暂存）
10. git log：查看项目全部历史提交记录
11. git diff：查看未存入暂存区的文件代码差异

## 三、.gitignore 文件作用
用于配置Git不需要追踪、上传的文件/文件夹，例如IDE缓存文件、编译产物、日志、本地配置。配置后Git会自动忽略匹配文件，不会提交到远程仓库。

## 四、GitHub协作基础流程
1. Issues：用于提交程序bug、需求讨论、分配开发任务
2. Pull Request（PR）：向原项目仓库发起代码合并申请，用于团队代码评审、合并代码
